# Lumi 3D production asset

This directory is reserved for the approved production model. The application
must not switch from the existing 2D artwork until `lumi.glb` passes the visual
and technical acceptance checklist in `docs/lumi-3d-production-spec.md`.

Expected deliverable: `lumi.glb` with embedded textures, skeleton, facial
controls, and named animation clips. Do not place procedural placeholder models
here.
